About

A full-featured web companion for the Marshall CODE series, built from the official CODE MIDI Implementation Chart v2.1. Live control, SysEx preset transfer, local library, and Marshall Cloud browsing.

The amp's Master is a physical analog pot with no MIDI/SysEx address, so it can't be controlled from here — the knob is shown disabled for parity. Use Volume for loudness.

Not affiliated with Marshall Amplification. Use at your own risk.

Sign in to Marshall

Authenticates through the Marshall identity server via the local proxy. Your password is sent to Marshall, never stored. Once signed in you can load your saved My Library presets; Official / Community presets and device Favourites need no account.
